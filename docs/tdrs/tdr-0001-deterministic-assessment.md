# TDR 0001: Deterministic assessment

- Status: Accepted
- Date: 2026-07-21

Assessment criteria carry explicit integer points totalling 100. A result awards points only for passed known criteria. Unknown and duplicate result identifiers are rejected. Completion requires 80 points and all mandatory criteria. AI-generated explanations consume this result but cannot mutate it.

This keeps scoring reproducible, testable, provider-independent, and understandable to children and Guardians.
