# Paddle Pulse reference-module catalog design

## Catalog projection

Junior Coder path `1.3.0` contains nineteen module records. Paddle Pulse and
Road Hopper Rally are module `2.0.0`; the other seventeen records remain
version `1.1.0`. Paddle Pulse is estimated at 360 minutes across Court,
Controls, Motion, Bricks, States and Final Game missions.

The Paddle Pulse record owns product metadata, materials, unchanged pricing,
its seven-part 100-point rubric, six rewards and the exact external content
reference:

- package: `@plasius/learning-paddle-pulse`
- package version: `0.1.0`
- export: `PADDLE_PULSE_MODULE_V2`
- schema version: `2`
- digest: `19f3666bdb523a3faf069341b0bc748996b3db282f89171e3c9f0a373a8c8f7e`

## Completion and compatibility

The protected server assessment is the completion authority. A score of at
least 80 plus mandatory sandbox safety completes the module; the progress
adapter can mark skipped stages `mastery-satisfied`. Mission assessments remain
formative and gate normal sequential navigation at 80.

Path `1.1.0`, Paddle Pulse `1.1.0`, its mission-authoring bundle and its API
consumers are unchanged. The catalog imports no executable package code, so no
dependency cycle is introduced.

## Consumer checks

Consumers resolving path `1.3.0` verify all five exact reference fields and the
canonical exported JSON digest before selecting an entry point. Browser code
must not import `@plasius/learning-paddle-pulse/server`. A mismatch fails closed;
flag rollback selects no v2 workspace and does not mutate saved progress.
